# Dossier

Dossier is a desktop application for finding and browsing sounds in your own audio library.

This repository is the public home for Dossier releases, release notes, and issue reports. The application's source code is maintained privately and is not included here.

## Release status

The first public release is in preparation. No public installer has been published in this repository yet.

When a release is available, its notes will describe the supported platform, installation steps, and any required resources.

## Feedback

Use this repository's Issues page for bug reports and feature requests. For a bug report, include the Dossier version, operating system, steps to reproduce, and what you expected to happen.
